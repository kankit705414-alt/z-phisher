# 🧠 RSA Encryption and Decryption Project

## 🧩 Definition
RSA (Rivest–Shamir–Adleman) is one of the most common public key cryptographic algorithms.  
It uses two different keys – a **Public Key** for encryption and a **Private Key** for decryption.  
With RSA, a message encrypted with the public key can only be read when decrypted with the matching private key.

---

## 🎯 Outcomes / Learning
By the end of this practical, we will be able to:

- Understand the use of public and private keys in RSA.  
- Generate RSA key pairs using an online tool.  
- Encrypt a message with the Public Key.  
- Decrypt the ciphertext using the Private Key.  
- Check that the decrypted text matches the original message.  

---

## 🛠️ Required Tools
- Laptop/PC with Internet connection  
- Web browser (Chrome / Edge / Firefox)  
- RSA Encryption/Decryption Tool: [https://www.devglan.com/online-tools/rsa-encryption-decryption](https://www.devglan.com/online-tools/rsa-encryption-decryption)  
- A simple sample message for testing

# 🧠 OpenStego Steganography Project

## 🧩 Definition
**OpenStego** is an open-source steganography tool used to hide secret data inside cover files such as images.  
It can also extract hidden messages whenever required and supports digital watermarking to detect tampering.

---

## 🎯 Outcomes / Learning
By the end of this practical, we will be able to:

- Understand the concept of steganography and its applications.  
- Use OpenStego software to embed and extract hidden messages.  
- Protect data privacy by hiding information inside media files.  
- Verify extracted messages to ensure successful data recovery.

---

## 🛠️ Required Tools
- Laptop/PC with Windows or Linux OS  
- **OpenStego** software (latest version)  
- Sample image file (`.jpg`, `.png`) as cover file  
- Text file containing secret message  

---

## ⚙️ Working Steps

### **Step 1:**  
Open the **OpenStego** application on your computer.  
Search for it from the Start menu or desktop shortcut.

### **Step 7: Extracting Data**  
To retrieve the secret message later:
1. Open OpenStego and click on **Extract Data**.  
2. Select the stego image created earlier as the **Input Stego File**.  
3. Choose an output folder for the recovered text file.  
4. Enter the same password if you used one earlier.  
5. Click **Extract Data** to reveal the hidden message.
